## The product

| Tier | Price | Seats | What members get |
|---|---|---|---|
| Watchlist | $0 | Open | Delayed calls, public record, weekly recap. Funnel only |
| Signal | $249/mo or $2,490/yr | Open | Live alerts on all timeframes (1D, 2D, 3D, 5D, weekly) with tags, entry, invalidation and leverage band; weekly report; Telegram + Discord; biweekly AMA |
| Prime | $799/mo or $7,990/yr | 60, by application | Signal plus a monthly live session with Jared, private channel, full stats per setup |
| Inner Table | $2,500/mo or $25,000/yr | 20, invite or application | Prime plus live view of Jared's positions, optional follow-trading in the member's own account, quarterly 1:1, private dinners |

Inner Table opens in model month 4 (~Apr 2027) and only if Jared is trading
live with a timestamped fill log and counsel approves follow-trading. No
custody, no pooled funds, no performance fees.

Leverage guidance: default 0.5–1x, hard cap 2x, isolated margin, exit at
invalidation, never add to a loser, skip when funding is extreme.

Public record: every call hashed when made, revealed later, misses kept.
Fields: direction, entry, exit, timing, tag, result.
