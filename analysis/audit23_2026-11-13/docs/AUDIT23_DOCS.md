**Top line:** 56 documents read (13 docs and pages, 20 code files' docstrings and comments, 23 test file headers), about 690 statements checked; 43 findings: (1) wrong 6, (2) stale 9, (3) loose or incomplete 24, (4) reads as a trade/return 4.

/home/claude/ctzb-data; code was run only in a copy (`audit23d/repo`), where the pipeline was rebuilt
(refresh → grade → extras → stack → cards → regression → feed, all steps success): the rebuilt feed matches
the committed one except timestamps and step order, so the committed feed is today's. Entry quality only:
everything here is about computed signals' 60-day records; there are no fills, no exits, no strategy return.

## What matters most

- **F1**: the spec says `open_signals[].confirmations` is plain words; the feed carries lens codes ("GAP + FASTCT").

- **X1**: CONTEXT still describes a dashboard refresh task that copies outputs and notifies; that is now the ctzb-dashboard Worker.
- **F5 / F6 / F7**: ETH samples start in 2020, grade_odds carries four ETH flag rows, and active_confluences is always empty on live and example cards; the spec says none of this.
